# Simulador de saturación de un TC

Simulación animada de cómo se satura el núcleo de un transformador de corriente (TC) y qué corriente recibe el relé de protección.

Se puede elegir entre cuatro casos (normal, mucha corriente, falla con componente de continua y núcleo ya magnetizado) y ver en paralelo la corriente real contra la que llega al relé y el punto de trabajo sobre la curva de magnetización B-H.

Modelo simplificado con fines didácticos: carga resistiva y curva de magnetización sin histéresis.
